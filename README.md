# 🌟 Animated Employee Directory (React Assignment 3)

## 🌐 Live Demo
Check out the live application here: [Animated Employee Directory Live](https://employeedirectory-iota.vercel.app/)

A dynamic, interactive employee management application built with React. This project demonstrates core React concepts like **State Management (useState)**, **Event Handling**, and **Conditional Rendering**, all wrapped in a visually striking, heavily animated User Interface.

---

## 🚀 Features
* **✨ Full CRUD Operations:** Seamlessly Add, Edit, and Delete employee records.
* **🔍 Smart Search & Filter:** Real-time search by Employee Name or ID, and dropdown filtering by Department.
* **📊 Live Counter:** A dynamic badge that instantly updates to show the current number of displayed employees.
* **🎨 Crazy Animations:** 
  * Continuous animated gradient backgrounds.
  * Smooth slide-in and bounce effects for employee cards.
  * Pulsing glow effects on key UI elements.
* **📱 Responsive Design:** Grid layout that adapts to different screen sizes.

## 🛠️ Installation & Running Locally

Follow these steps to run the project on your local machine:

1. **Clone the repository:**
   \\\ash
   git clone https://github.com/nilimeshbasu/Employee-Directory.git
   \\\

2. **Navigate into the project folder:**
   \\\ash
   cd employee-directory
   \\\

3. **Install dependencies:**
   \\\ash
   npm install
   \\\

4. **Start the development server:**
   \\\ash
   npm start
   \\\
